4マルチエージェント

サブエージェントはコールドで起動し、互いのログを見られない。 共有手段はファイルだけ。
  • 走らせる前に契約を固定。ファイル所有権・盤面の board[y][x]・npm scripts
  • 並列では相互参照は成立しない。本物になるのは次ラウンドから
  • 報告は主張であって成果物ではない。差分を読み、挙動を自分で再実行してからコミット
  • 権限・設定ファイルの変更は必ず自分で検証（今回 npm install の許可を削除）
