# Angry Blobs 🐦🐷

スマートフォンのブラウザで遊べる、Angry Birds 風のスリングショット物理パズルゲーム。

## 遊び方

1. このディレクトリで簡易サーバーを起動:

   ```bash
   cd angry-birds
   python3 -m http.server 8000
   ```

2. スマホ(または PC)のブラウザで `http://<マシンのIP>:8000` を開く
   (PC なら `http://localhost:8000`)

3. 🐦 を指でドラッグして引っぱり、離して発射!ブタ 🐷 を全部倒せばクリア。

- **赤い鳥**: ふつうの鳥
- **黄色い鳥**: 飛行中に画面をタップすると加速する
- 素材の硬さ: 氷 < 木 < 石
- 残った鳥 1 羽につき +10,000 点ボーナス

全 3 レベル。ベストスコアは端末(localStorage)に保存されます。

## 技術構成

- **物理エンジン**: [Matter.js](https://brm.io/matter-js/) 0.20.0(`lib/matter.min.js` に同梱、ネットワーク不要)
- **描画**: Canvas 2D。画像アセットなしで全部コード描画
- **入力**: Pointer Events(タッチとマウスの両対応)
- **音**: WebAudio によるシンセ効果音(ミュートボタンあり)
- ビルド不要・依存インストール不要。静的ファイル 3 つだけで動きます

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | ページ・HUD・オーバーレイ UI・スタイル |
| `game.js` | ゲームロジック(物理、レベル、描画、入力、効果音) |
| `lib/matter.min.js` | Matter.js 本体(同梱) |

## レベルを追加するには

`game.js` の `LEVELS` 配列にエントリを足すだけ:

```js
{
  birds: ['red', 'yellow'],              // 使える鳥のキュー
  blocks: [[x, y, 幅, 高さ, 'wood']],    // 素材: wood / ice / stone
  pigs: [[x, y, 半径]],
}
```

座標はワールド座標(1600×900、地面の上端が y=840)です。
