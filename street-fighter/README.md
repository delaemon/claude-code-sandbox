# STREET BRAWLER VI

ストリートファイター6風のブラウザ対戦格闘ゲーム。依存ライブラリなしの単一HTMLファイルで、`index.html` をブラウザで開くだけで遊べます。

## 遊び方

```bash
# そのまま開く
open street-fighter/index.html        # macOS
xdg-open street-fighter/index.html   # Linux

# またはローカルサーバーで
python3 -m http.server -d street-fighter 8000
# → http://localhost:8000
```

タイトルで **ENTER** → モード選択(vs CPU 難易度3段階 / 2P対戦)→ 試合開始。2ラウンド先取・99秒制。

## 操作方法

### Player 1

| 操作 | キー |
|---|---|
| 移動 / ジャンプ / しゃがみ | W A S D |
| 弱パンチ / 強パンチ | U / I |
| 弱キック / 強キック | J / K |
| 必殺技ボタン(モダン操作) | O(ニュートラル=波動拳、前+O=昇龍拳) |
| ドライブインパクト | L |
| クリティカルアーツ(SA) | SPACE(ゲージMAX時) |
| ガード | 相手と反対方向に入力(しゃがみガードで下段対応) |

### Player 2(2P対戦時)

| 操作 | キー |
|---|---|
| 移動 / ジャンプ / しゃがみ | 矢印キー |
| 弱P / 強P / 弱K / 強K | 1 / 2 / 3 / 4 |
| 必殺技ボタン | 5 |
| ドライブインパクト | 6 |
| クリティカルアーツ | ENTER |

### クラシックコマンド入力(両プレイヤー共通)

- **波動拳**: ↓↘→ + パンチ(強パンチで弾速アップ)
- **昇龍拳**: →↓↘ + パンチ(無敵時間あり・対空)
- **クリティカルアーツ**: ↓↘→↓↘→ + パンチ(ゲージMAX時、飛び道具を貫通する超必殺)

## システム

- **体力・タイマー・ラウンド制**: 2本先取、タイムアップ時は体力の多い方が勝ち
- **ドライブゲージ**(緑・6本): ドライブインパクトで消費、ガードで削られる。枯渇するとバーンアウト(回復が遅くなる)
- **ドライブインパクト**: 発生前にアーマー2発。ヒットで大きく吹き飛ばしてコンボチャンス
- **SAゲージ**(青): 攻撃のヒット・被弾で増加。MAXでクリティカルアーツ解放
- **コンボ補正**: 連続ヒットでダメージが逓減、HITS カウンター表示
- **上段/下段/中段**: しゃがみ攻撃は下段(立ちガード不可)、ジャンプ攻撃は中段(しゃがみガード不可)
- **削りダメージ**: 必殺技はガードしてもチップダメージ(チップKOなし、SAを除く)
- **CPU AI**: EASY / NORMAL / HARD の3段階。距離に応じた立ち回り、ガード反応、割り込み昇龍まで対応

## 技術メモ

- 1280×720 の Canvas 2D、`requestAnimationFrame` による 60fps 更新
- キャラクターはスケルトン(関節+カプセル肢体)によるプロシージャル描画でスプライト画像不要
- 効果音は WebAudio API によるシンセ生成
- コマンド入力はテンキー表記の方向履歴バッファ(500ms窓)で判定
